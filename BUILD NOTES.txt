Stills & Reels 2.2 - source
===========================
C# WinForms, .NET Framework 4.8. About 17,000 lines in src/. Built on Linux with Mono (mcs) and
mingw windres; the result is a single Windows exe.

Build
  1. Put the FFmpeg 7.1 Windows build (gyan.dev "essentials", GPLv3) at engine/ffmpeg.exe,
     then gzip it:  gzip -9 -k engine/ffmpeg.exe   (gives engine/ffmpeg.exe.gz)
     That build was taken from the imageio-ffmpeg 0.6.0 wheel. The app checks the unpacked file
     against the SHA-256 in src/BuildInfo.cs, so a different build needs that value updating.
  2. ./build.sh   -> build/StillsAndReels.exe
  Needs: mono-mcs (with the 4.8 reference assemblies, including Accessibility.dll) and mingw-w64 (windres).

Layout
  src/ExplorerWatcher.cs follows File Explorer windows and the desktop
  src/PickupWatcher.cs   follows clicks in other apps (pictures on web pages, files in Open/Save dialogs)
                         and the clipboard
  src/MainForm.cs        main window, menus, modes (Pictures / Edit / Videos / Edit video), snips
  src/Snip.cs            picture snip       src/VideoSnip.cs   screen recording
  (VideoSnip.cs captures with ddagrab + hwdownload when a trial run succeeds, else gdigrab)
  src/PcSound.cs         PC sound for recordings (WASAPI loopback, streamed to FFmpeg over a named pipe;
                         the bundled FFmpeg has no loopback input of its own)
  src/EditSession.cs, EditSidebar.cs, ImageCanvas*.cs   picture editing (paste layer etc.)
  src/VideoView.cs, FFmpeg.cs   video playback and the bundled FFmpeg
  src/VideoQuality.cs     FFmpeg quality settings shared by recording, editor decode and export
                         (colour standard, scaling, lossless capture, final H.264 encode)
  src/VideoProject.cs    project model (.srproj; older .ppvproj also opens)
  src/MediaLibrary.cs, Compositor.cs, EditorEngine.cs, Timeline.cs, EditorPanels.cs,
  src/VideoEditorView.cs, ExportDialog.cs   the video editor
  tests/                 logic.cs (regression test, loads the built exe by reflection),
                         CloseTest.cs (opens the snip windows and closes the app),
                         HideTest.cs (New snip hides only the Snip window, not the main window;
                         run with 'picture' or 'video'),
                         pickup.cs (pick-up helpers: hidden extensions, picked-picture files),
                         ExportTest.cs (exports one video through the editor's ExportJob; compare
                         the result with the source using FFmpeg's psnr filter),
                         FinishTest.cs (encodes two lossless recording segments with ScreenRecorder.Finish).
                         Both need an ffmpeg on the PATH (Linux: the app uses the system ffmpeg there).
                         AvSyncTest.cs (records with live screen capture and PC sound through the app's own
                         SoundPump and argument builder; checks stalls, dropped frames and sync. It is
                         compiled together with src/*.cs: see the comment at the top of the file. Run it
                         on Xvfb :99 with 'pc', 'pc+mic', 'none' or 'pc+slow').
                         TEST PLAN.md lists every test that must pass before a build is handed over.
