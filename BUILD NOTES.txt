Stills & Reels 2.2 - source
===========================
C# WinForms, .NET Framework 4.8. About 17,000 lines in src/. Built on Linux with Mono (mcs) and
mingw windres; the result is a single Windows exe.

Build
  1. Put the FFmpeg 7.1 Windows build (gyan.dev "essentials", GPLv3) at engine/ffmpeg.exe,
     then gzip it:  gzip -9 -k engine/ffmpeg.exe   (gives engine/ffmpeg.exe.gz)
     That build was taken from the imageio-ffmpeg 0.6.0 wheel. The app checks the unpacked file
     against the SHA-256 in src/BuildInfo.cs, so a different build needs that value updating.
  2. ./build.sh   -> build/StillsAndReels.exe
  Needs: mono-mcs (with the 4.8 reference assemblies) and mingw-w64 (windres).

Layout
  src/MainForm.cs        main window, menus, modes (Pictures / Edit / Videos / Edit video), snips
  src/Snip.cs            picture snip       src/VideoSnip.cs   screen recording
  src/EditSession.cs, EditSidebar.cs, ImageCanvas*.cs   picture editing (paste layer etc.)
  src/VideoView.cs, FFmpeg.cs   video playback and the bundled FFmpeg
  src/VideoProject.cs    project model (.srproj; older .ppvproj also opens)
  src/MediaLibrary.cs, Compositor.cs, EditorEngine.cs, Timeline.cs, EditorPanels.cs,
  src/VideoEditorView.cs, ExportDialog.cs   the video editor
  tests/                 logic.cs (regression test, loads the built exe by reflection),
                         CloseTest.cs (opens the snip windows and closes the app),
                         HideTest.cs (New snip hides only the Snip window, not the main window;
                         run with 'picture' or 'video')
